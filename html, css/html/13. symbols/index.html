Simbol Umum di HTML

Euro sign: € → €

Dollar sign: $ → $

Pound sign: £ → £

Yen sign: ¥ → ¥

Kurang dari: < → <

Lebih dari: > → >

Kurang dari atau sama dengan: ≤ → ≤

Lebih dari atau sama dengan: ≥ → ≥

Tidak sama dengan: ≠ → ≠

Plus minus: ± → ±

Perkalian (×): × → ×

Pembagian (÷): ÷ → ÷

Panah kanan: → → →

Panah kiri: ← → ←

Panah atas: ↑ → ↑

Panah bawah: ↓ → ↓

Panah ganda kanan: ⇒ → ⇒

Panah ganda kiri: ⇐ → ⇐

Copyright: © → ©

Registered: ® → ®

Trademark: ™ → ™

Degree (derajat): ° → °

Bullet: • → •

Middle dot: · → ·

Em dash: — → —

Non-breaking space:   → (spasi tidak terputus)

Quotation marks: " → "

Ampersand: & → &

Infinity: ∞ → ∞

Alpha: α → α

Beta: β → β

Pi: π → π

Summation: ∑ → ∑

Square root: √ → √
